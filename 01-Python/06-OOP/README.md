# Python Object-Oriented Programming

A hands-on exploration of Object-Oriented Programming (OOP) in Python, focusing on classes, objects, attributes, methods, encapsulation, inheritance, and special methods.

## Overview

This module focuses on understanding and applying Python's object-oriented programming concepts through practical coding exercises.

The objective is to strengthen conceptual understanding, improve retention, and develop the ability to implement OOP principles independently.

## Concepts Covered

- **Classes and Objects:** Defining classes and creating instances.
- **Constructors:** Initializing objects using `__init__()`.
- **Instance Attributes:** Managing data specific to individual objects.
- **Class Attributes:** Sharing data across instances.
- **Instance Methods:** Implementing behavior within classes.
- **Special Methods:** Exploring `__repr__()` and operator overloading.
- **Encapsulation:** Managing access to object attributes.
- **Inheritance:** Extending existing classes to reuse and specialize behavior.
- **`super()`:** Reusing parent-class initialization and functionality.

## Practical Implementation

The notebook uses a bank-account model to explore these concepts through code, including:

- Account creation and account-number assignment.
- Deposits and withdrawals.
- Balance management and transaction validation.
- Object representation.
- Attribute access and encapsulation.
- Interactions between objects.
- Extending a base account class with a savings-account implementation.

## Learning Objectives

By completing this module, I aim to:

1. Understand the relationship between classes, objects, attributes, and methods.
2. Distinguish class attributes from instance attributes.
3. Apply constructors and special methods.
4. Understand encapsulation and inheritance.
5. Reuse and extend functionality using `super()`.
6. Implement OOP concepts without relying on reference code.
7. Recognize opportunities to use object-oriented design in larger applications.
